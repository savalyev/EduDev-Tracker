### 1.2 Архитектура приложения

EduDev Tracker — кроссплатформенное приложение, разработанное на платформе **.NET MAUI** (Multi-platform App UI). Приложение функционирует полностью автономно, без подключения к серверу.

**Ключевые архитектурные характеристики:**

- **Все данные хранятся локально** на устройстве пользователя в базе данных SQLite. Облачная синхронизация отсутствует.
- **Единый кодовый базис** обеспечивает работу на Windows, Android, iOS и macOS из одного проекта.
- **Архитектурный шаблон MVVM** (Model-View-ViewModel) — отвечает за разделение логики и интерфейса.
- **Файл базы данных:** `edudev-tracker.db3`, располагается в папке данных приложения на устройстве.
- **Офлайн-режим:** приложение не требует подключения к интернету для основных функций (трекинг, заметки, конвертеры, аналитика).

### 1.3 Глоссарий терминов и сокращений

| Термин / Сокращение | Определение |
|---|---|
| **Привычка** | Регулярное действие, которое пользователь отслеживает ежедневно или по расписанию (например: «Утренняя зарядка», «Чтение 30 минут»). |
| **Стрик** | Непрерывная серия дней, в которые привычка была выполнена. Обнуляется при пропуске дня согласно расписанию. |
| **Заморозка привычки** | Временное приостановление требования выполнения привычки без потери стрика. Используется при болезни или отпуске. |
| **Архив** | Область хранения деактивированных элементов (привычек, задач, заметок). Данные сохраняются, но не отображаются в основном списке. |
| **Помодоро / Помодоро-сессия** | Отрезок сосредоточенной работы, как правило 25 минут, по методике Помодоро. После нескольких рабочих блоков следует длинный перерыв. |
| **Пресет** | Набор настроек помодоро-таймера (длительность работы, перерывов, число циклов), сохранённый под именем. |
| **Фаза** | Один период в цикле помодоро: Работа, Короткий перерыв или Длинный перерыв. |
| **Цикл** | Полная последовательность: N рабочих фаз с короткими перерывами, завершающаяся длинным перерывом. |
| **Лог** | Запись о факте выполнения привычки в конкретную дату с указанием значения (для количественных типов). |
| **Конвертер** | Инструмент для перевода данных из одного формата в другой (числа, цвета, временные зоны, форматы данных). |
| **FTS** | Full-Text Search — полнотекстовый поиск. Используется в модуле заметок для быстрого поиска по содержимому. |
| **SQLite** | Встроенная реляционная база данных, не требующая отдельного сервера. |
| **MAUI** | .NET Multi-platform App UI — технология Microsoft для разработки кроссплатформенных приложений. |
| **OAuth** | Открытый протокол авторизации. Позволяет войти через учётную запись Google или GitHub. |
| **Дедлайн** | Крайняя дата и время выполнения задачи. |
| **Канбан** | Визуальный метод управления задачами с разбивкой по статусам (Открыто / В работе / Выполнено / Отменено). |
| **Markdown** | Язык разметки текста. Используется в редакторе заметок: `**жирный**`, `*курсив*`, `# Заголовок`. |

## 2. Назначение и условия применения

### 2.1 Назначение приложения

**EduDev Tracker** — персональный трекер продуктивности, предназначенный для:

- Формирования и отслеживания полезных привычек с ведением статистики и стриков
- Управления задачами с приоритетами, дедлайнами и повторяющимися событиями
- Ведения структурированных заметок в формате Markdown с поиском и вложениями
- Управления временем методом Помодоро с настраиваемыми пресетами
- Конвертации данных: числовые системы, цвета, временные зоны, форматы JSON/XML, URL
- Анализа личной продуктивности с визуализацией статистики и экспортом отчётов

Приложение ориентировано на студентов, разработчиков и всех, кто стремится улучшить личную эффективность и систематизировать ежедневные задачи.

### 2.2 Режимы работы

| Режим | Описание |
|---|---|
| Однопользовательский (основной) | Все данные привязаны к одному активному профилю на устройстве |
| Локальный (без аккаунта) | Полноценная работа без регистрации; данные хранятся только на устройстве |
| Аккаунт с паролем | Профиль с email и паролем; данные по-прежнему хранятся локально |

> **Важно:** Независимо от способа входа, все данные сохраняются локально на устройстве. Синхронизация между устройствами не поддерживается.

### 2.3 Системные требования

#### Windows (Desktop)

| Параметр | Минимальные требования |
|---|---|
| Операционная система | Windows 10 версия 1904 (Build 19041) или новее; Windows 11 |
| Разрядность | 64-бит (x64) |
| Оперативная память | 4 ГБ RAM |
| Место на диске | 300 МБ свободного пространства |
| Среда выполнения | .NET 10 Runtime (входит в состав установщика) |
| Дополнительно | Поддержка уведомлений Windows Action Center |

## 3. Описание основных функций

### 3.1 Запуск и авторизация

#### Назначение

Модуль авторизации обеспечивает идентификацию пользователя и изоляцию данных по профилям. Поддерживает три способа использования: локальный режим (без аккаунта), вход с паролем и OAuth-вход.

#### 3.1.1 Регистрация нового аккаунта

**Порядок действий:**

1. Запустите приложение EduDev Tracker.
2. На экране входа нажмите кнопку **«Регистрация»** или **«Создать аккаунт»**.
3. Заполните поля:
   - **Имя** — ваше имя или псевдоним (минимум 2 символа)
   - **Email** — адрес электронной почты в формате `example@domain.com`
   - **Пароль** — не менее 8 символов
   - **Подтверждение пароля** — повторите пароль точно так же
4. Нажмите кнопку **«Зарегистрироваться»**.

**Ожидаемый результат:** Профиль создан, автоматически выполнен вход, открывается главный экран приложения (Dashboard).
**Возможные ошибки:**

| Сообщение | Причина | Действие |
|---|---|---|
| «Имя слишком короткое» | Имя содержит менее 2 символов | Введите имя длиннее 2 символов |
| «Некорректный формат email» | Email не соответствует формату | Проверьте правильность ввода email |
| «Пароль слишком короткий» | Пароль содержит менее 8 символов | Придумайте пароль от 8 символов |
| «Пароли не совпадают» | Пароль и подтверждение различаются | Введите одинаковые значения в оба поля |
| «Email уже занят» | Аккаунт с таким email уже существует | Используйте другой email или войдите в существующий аккаунт |

---

#### 3.1.2 Вход в существующий аккаунт

**Порядок действий:**

1. Запустите приложение.
2. В поле **«Email»** введите адрес электронной почты.
3. В поле **«Пароль»** введите пароль. Для просмотра введённых символов нажмите иконку глаза справа от поля.
4. Нажмите кнопку **«Войти»**.

**Ожидаемый результат:** Выполнен вход в профиль, открывается главный экран.

**Возможные ошибки:**

| Сообщение | Причина | Действие |
|---|---|---|
| «Неверный пароль» | Введён неправильный пароль | Проверьте пароль и повторите ввод |
| «Аккаунт с таким email не найден» | Email не зарегистрирован | Проверьте email или создайте новый аккаунт |

---

#### 3.1.3 Локальный режим (без аккаунта)

**Порядок действий:**

1. На экране входа нажмите кнопку **«Продолжить без входа»** или **«Локальный режим»**.
2. Приложение создаёт анонимный локальный профиль.
3. Открывается главный экран.

**Ожидаемый результат:** Все функции приложения доступны без создания аккаунта. Данные хранятся локально и привязаны к устройству.

> **Примечание:** В локальном режиме email не задан. В профиле отображается метка «Локальный режим».

### 3.2 Главный экран (Dashboard)

#### Назначение

Dashboard — сводный экран, отображающий актуальное состояние всех модулей приложения в одном месте. Позволяет оценить прогресс дня и недели, а также быстро перейти к основным действиям.

#### Состав экрана

**Шапка:**
- Приветствие, меняющееся в зависимости от времени суток:
  - 00:00–05:59 — «Доброй ночи,»
  - 06:00–11:59 — «Доброе утро,»
  - 12:00–16:59 — «Добрый день,»
  - 17:00–21:59 — «Добрый вечер,»
- Текущая дата (день недели, число и месяц)

**Прогресс-кольцо недели:**
- Показывает процент выполнения целей текущей недели
- Формула: (выполненные привычки + закрытые задачи + сессии помодоро) по отношению к плановым показателям

**Карточки модулей:**

| Карточка | Содержание |
|---|---|
| Привычки | Число активных привычек, выполнено сегодня из общего числа, статистика за неделю |
| Задачи | Список сегодняшних задач (до 10), число просроченных, статус каждой задачи |
| Помодоро | Суммарное время фокуса сегодня, число завершённых сессий, активный пресет |

**График активности за 7 дней:**
- Столбчатый график за последние 7 дней
- Высота столбца пропорциональна суммарной активности (привычки + задачи + помодоро)
- Сегодняшний день выделен цветом

**Быстрые действия:**
- Кнопка «Добавить привычку» → переход к форме создания привычки
- Кнопка «Добавить задачу» → переход к форме создания задачи
- Кнопка «Запустить помодоро» → переход к помодоро-таймеру

### 3.3 Модуль привычек

#### Назначение

Модуль привычек позволяет создавать, отслеживать и анализировать регулярные действия. Поддерживает три типа привычек, настраиваемое расписание и систему стриков для мотивации.

---

#### 3.3.1 Создание привычки

**Порядок действий:**

1. В меню перейдите в раздел **«Привычки»**.
2. Нажмите кнопку **«+»** или **«Добавить привычку»** в правом верхнем углу.
3. Откроется форма создания. Заполните поля:

   **Шаг 1 — Название и описание:**
   - **Название** *(обязательно)* — краткое название привычки, например «Утренняя зарядка»
   - **Описание** *(опционально)* — цель или дополнительная информация

   **Шаг 2 — Иконка:**
   - Выберите иконку из предустановленного набора (6 вариантов: стандартная, бег, вода, спорт, книга, мозг)
   - Выбранная иконка будет отображаться рядом с названием привычки в списке

   **Шаг 3 — Тип привычки:**
   - **Бинарная** — фиксирует факт выполнения (выполнено / не выполнено)
   - **Количественная** — фиксирует числовое значение (например, «100 отжиманий»)
   - **По времени** — фиксирует продолжительность (например, «30 минут медитации»)

   **Шаг 4 — Целевое значение** (для Количественной и По времени):
   - **Целевое значение** — число (например, `30`)
   - **Единица измерения** — единица (например, `минут`, `отжиманий`, `страниц`)

   **Шаг 5 — Расписание:**
   - Отметьте дни недели, в которые необходимо выполнять привычку
   - Можно выбрать любое сочетание дней с Пн по Вс
   - Для ежедневной привычки выберите все 7 дней

   **Шаг 6 — Напоминание:**
   - Установите время напоминания (формат ЧЧ:ММ)
   - В установленное время поступит push-уведомление

4. Нажмите кнопку **«Сохранить»**.

**Ожидаемый результат:** Привычка появляется в общем списке. Если настроены уведомления, они будут приходить в установленное время по указанным дням.

**Возможные ошибки:**

| Ситуация | Причина | Действие |
|---|---|---|
| Кнопка «Сохранить» неактивна | Поле «Название» пустое | Введите название привычки |
| Уведомление не пришло | Уведомления отключены в настройках ОС | Разрешите уведомления для приложения в настройках устройства |

---

#### 3.3.2 Просмотр и выполнение привычек

**Список привычек** отображает все активные (не заархивированные) привычки с информацией:
- Иконка и название
- Тип привычки (Бинарная / Количественная / По времени)
- Текущий стрик (число дней подряд)
- Прогресс на этой неделе

**Отметка выполнения:**

- **Бинарная привычка:** нажмите чекбокс справа от названия — привычка помечается как выполненная на сегодня.
- **Количественная / По времени:** нажмите чекбокс — появится поле для ввода числового значения (например, «25» минут или «80» отжиманий). Введите значение и подтвердите.

**Ожидаемый результат:** Привычка отмечена выполненной. Стрик увеличивается при соблюдении расписания.

---

#### 3.3.3 Фильтрация и статистика списка

В верхней части экрана доступны фильтры:
- **По типу:** Все типы / Бинарная / Количественная / По времени
- **По периоду:** Сегодня / Неделя

Под списком привычек отображается **7-дневный мини-календарь**:
- Зелёный день — все привычки выполнены
- Красная цифра — число пропущенных привычек в этот день
- Нажатие на день — просмотр выполнения за этот день

Сводная статистика:
- «Сегодня: X активных, Y выполнено»
- «Процент выполнения: Z%»

---

#### 3.3.4 Детальный просмотр привычки

**Порядок действий:**

1. Нажмите на название привычки в списке → откроется страница деталей.

На странице отображается:
- Иконка и название
- Тип, расписание, время напоминания
- Текущий стрик («— дн.» если нет)
- Состояние заморозки и архива

**Редактирование:**
1. Нажмите кнопку **«Редактировать»**.
2. Измените название или описание.
3. Нажмите **«Сохранить»** для применения или **«Отмена»** для отклонения.

**Архивация привычки:**
1. Нажмите **«Архивировать»**.
2. Подтвердите действие в диалоге подтверждения.

**Ожидаемый результат:** Привычка перемещается в архив. История логов и стрик сохраняются. Привычка не отображается в основном списке.

**Удаление привычки:**
1. Нажмите **«Удалить»**.
2. Подтвердите удаление.

**Ожидаемый результат:** Привычка и все её логи безвозвратно удалены.

---

#### 3.3.5 Архив привычек

**Порядок действий:**

1. В разделе «Привычки» нажмите кнопку **«Архив»** в заголовке.
2. Откроется список заархивированных привычек.

**Доступные действия:**
- **«Восстановить»** — привычка возвращается в активный список с сохранённой историей
- **«Удалить»** — безвозвратное удаление привычки и всех её логов

### 3.4 Модуль задач

#### Назначение

Модуль задач предназначен для планирования и отслеживания задач с приоритетами, дедлайнами, категориями и повторяющимися событиями. Поддерживает три режима отображения: список, календарь и канбан-доска.

---

#### 3.4.1 Создание задачи

**Порядок действий:**

1. Перейдите в раздел **«Задачи»**.
2. Нажмите кнопку **«+»** или **«Добавить задачу»**.
3. Заполните форму:

   **Название** *(обязательно)* — от 3 до 300 символов, например «Подготовить отчёт»

   **Описание** *(опционально)* — подробности задачи

   **Категория** *(опционально)* — текстовая метка для группировки (например, «Работа», «Учёба»)

   **Приоритет** — выберите один из вариантов:

   | Приоритет | Описание |
   |---|---|
   | Низкий | Задача без срочности |
   | Средний | Обычная задача |
   | Высокий | Требует выполнения в ближайшее время |
   | Срочный | Критически важная задача |

   **Дедлайн** — дата и время крайнего срока выполнения. Дата не может быть в прошлом.

   **Повторение** *(опционально)*:
   - Тип повторения: Ежедневно / Еженедельно / Ежемесячно
   - Интервал: каждые N дней/недель/месяцев
   - Для еженедельного — выберите дни недели (минимум один)
   - Дата окончания повторения *(опционально)*

4. Нажмите **«Создать»**.

**Ожидаемый результат:** Задача создана и отображается в списке в соответствующей группе по дедлайну. Появляется уведомление «Задача создана».

**Возможные ошибки:**

| Сообщение | Причина | Действие |
|---|---|---|
| «Название обязательно» | Поле пустое | Введите название задачи |
| «Слишком короткое название» | Менее 3 символов | Увеличьте название |
| «Дата не может быть в прошлом» | Выбранный дедлайн уже прошёл | Укажите будущую дату |
| «Выберите хотя бы один день» | Еженедельное повторение без выбранных дней | Отметьте хотя бы один день недели |

#### 3.4.2 Режим отображения: Список

По умолчанию задачи отображаются в виде списка, сгруппированного по срокам:

| Группа | Условие |

Фильтрация по приоритету (кнопки вверху экрана): Все / Срочный / Высокий / Средний / Низкий / Просрочено

#### 3.4.3 Режим отображения: Календарь

#### 3.4.4 Режим отображения: Канбан-доска

2. Отображаются 4 колонки:

3. В каждой карточке задачи отображаются: название, приоритет, дедлайн.
4. Для перемещения задачи в другую колонку — откройте детали задачи и измените статус.

### 3.5 Модуль заметок

#### Назначение

Модуль заметок — полноценный редактор с поддержкой Markdown, организацией по категориям, поиском, вложениями и историей версий. Подходит для ведения конспектов, дневника, списков и технических заметок.

---

#### 3.5.1 Создание заметки

**Порядок действий:**

1. Перейдите в раздел **«Заметки»**.
2. Нажмите кнопку **«+»** или **«Создать заметку»**.
3. Создаётся новая заметка с заголовком «Новая заметка».
4. Нажмите на заголовок и введите своё название.
5. В области содержимого введите текст.

**Ожидаемый результат:** Заметка создана и автоматически сохраняется. В нижней части редактора отображается время сохранения («Сохранено в ЧЧ:ММ»).

---

#### 3.5.2 Редактирование с Markdown

Редактор поддерживает форматирование текста через панель инструментов:

| Кнопка | Действие | Синтаксис |
|---|---|---|
| **Ж** | Жирный текст | `**текст**` |
| *К* | Курсив | `*текст*` |
| `Код` | Инлайн-код | `` `код` `` |
| H1 | Заголовок 1-го уровня | `# Заголовок` |
| H2 | Заголовок 2-го уровня | `## Заголовок` |
| H3 | Заголовок 3-го уровня | `### Заголовок` |
| Список | Маркированный список | `- элемент` |
| Нум. | Нумерованный список | `1. элемент` |
| Задача | Чекбокс-задача | `- [ ] задача` |
| Ссылка | Вставка ссылки | `[текст](url)` |
| ```...``` | Блок кода | Тройные обратные кавычки |
| --- | Разделитель | `---` |

**Переключение между редактором и превью:**
- Нажмите кнопку **«Превью»** или **«Редактор»** в верхней части — переключение между режимом ввода и режимом отображения отформатированного текста.

**Счётчик слов** отображается в нижней части экрана.

---

#### 3.5.3 Организация заметок

**Категории:**
1. В левой панели (или в меню) нажмите **«+ Категория»**.
2. Введите название категории и подтвердите.

**Закрепление заметки:**

- Закреплённые заметки отображаются в верхней части списка.
- Для просмотра только закреплённых — включите фильтр «Только закреплённые».

**Поиск:**
1. Нажмите иконку поиска или начните вводить текст в строку поиска.
2. Поиск осуществляется по заголовку и содержимому всех заметок.
3. Результаты обновляются в реальном времени.

---

#### 3.5.4 Вложения

**Добавление вложения:**
1. Откройте заметку.
2. Нажмите кнопку **«Прикрепить файл»** или **«Вложение»**.
3. Откроется диалог выбора файла.

**Ожидаемый результат:** Файл удалён из хранилища приложения и убран из списка вложений.

#### 3.5.5 История версий

### 3.6 Помодоро-таймер

#### Назначение

Помодоро-таймер реализует технику управления временем «Помодоро»: сосредоточенная работа чередуется с короткими перерывами, а каждые N циклов следует длинный перерыв. Поддерживает настраиваемые пресеты и привязку к задачам.

---

#### 3.6.1 Запуск таймера

**Порядок действий:**

1. Перейдите в раздел **«Помодоро»**.
2. В списке пресетов выберите нужный (по умолчанию — «Стандарт 25/5»).
3. *(Опционально)* Нажмите **«Выбрать задачу»** и привяжите активную задачу к сессии.
4. Нажмите кнопку **«Старт»**.
5. Запускается обратный отсчёт текущей фазы.

**Ожидаемый результат:** Таймер начинает отсчёт. Отображается оставшееся время (ЧЧ:ММ) и текущая фаза. В верхней части — индикатор «Сессия X из Y».

---

#### 3.6.2 Управление таймером

| Кнопка | Действие |
|---|---|
| **Пауза** | Приостановить таймер |
| **Продолжить** | Возобновить после паузы |
| **Пропустить фазу** | Перейти к следующей фазе без ожидания |
| **Завершить сессию** | Остановить и сбросить таймер (требует подтверждения) |

**Последовательность фаз (пример для пресета 25/5, 4 цикла):**
```
Работа 25м → Перерыв 5м → Работа 25м → Перерыв 5м →
Работа 25м → Перерыв 5м → Работа 25м → Длинный перерыв 20м
```

**Уведомления:**
- За 1 минуту до конца фазы — звуковое предупреждение
- По завершении фазы — звуковое уведомление и push-уведомление

> **Примечание:** Таймер продолжает работу в фоновом режиме. При сворачивании приложения на Android необходимо отключить оптимизацию батареи для корректной работы.

---

#### 3.6.3 Создание пресета

**Порядок действий:**

1. В разделе «Помодоро» перейдите на вкладку **«Пресеты»** или нажмите **«+ Новый пресет»**.
2. Заполните форму:

   | Поле | Диапазон | Описание |
   |---|---|---|
   | **Название** | 2+ символов | Имя пресета |
   | **Рабочий интервал** | 5–90 минут | Длительность фазы «Работа» |
   | **Короткий перерыв** | 1–30 минут | Длительность короткого перерыва |
   | **Длинный перерыв** | 5–60 минут | Длительность длинного перерыва |
   | **Циклов до длинного перерыва** | 1–8 | Число рабочих фаз перед длинным перерывом |
   | **По умолчанию** | Чекбокс | Использовать этот пресет при запуске |

3. Нажмите **«Сохранить»**.

**Ожидаемый результат:** Пресет появляется в списке. Превью показывает последовательность фаз и суммарное время полного цикла.

**Предустановленные пресеты:**

| Пресет | Работа | Корот. перерыв | Длин. перерыв | Циклов |
|---|---|---|---|---|
| Стандарт 25/5 | 25 мин | 5 мин | 20 мин | 4 |
| Глубокая работа 50/10 | 50 мин | 10 мин | 30 мин | 3 |
| Учёба 15/3 | 15 мин | 3 мин | 15 мин | 6 |

---

#### 3.6.4 Статистика помодоро

В разделе «Помодоро» нажмите вкладку **«Статистика»**:

- **Сегодня:** число завершённых рабочих сессий
- **Неделя:** общее число сессий, суммарное время фокуса
- **Месяц:** общее число сессий, среднее в день, лучший день
- **График по дням** — столбчатый график за последние 7 дней

### 3.7 Модуль конвертеров

#### Назначение

Модуль конвертеров предоставляет пять независимых инструментов для преобразования данных в различных форматах. Все конвертации автоматически сохраняются в историю.

---

#### 3.7.1 Конвертер числовых систем

**Переход:** Раздел «Конвертеры» → вкладка **«Числа»**

**Порядок действий:**
1. Введите число в поле ввода. Поддерживаются форматы:
   - Десятичное: `255`
   - Двоичное с префиксом: `0b11111111`
   - Восьмеричное с префиксом: `0o377`
   - Шестнадцатеричное с префиксом: `0xFF`
2. Результат отображается автоматически во всех системах счисления.

**Результаты отображаются в форматах:**

| Поле | Значение для 255 |
|---|---|
| Двоичное (Bin) | 11111111 |
| Восьмеричное (Oct) | 377 |
| Десятичное (Dec) | 255 |
| Шестнадцатеричное (Hex) | FF |
| Произвольная база (2–36) | Настраивается отдельно |

**Ожидаемый результат:** Мгновенное преобразование при вводе. При некорректном вводе отображается сообщение об ошибке.

---

#### 3.7.2 Конвертер цветов

**Переход:** Вкладка **«Цвет»**

**Порядок действий:**
1. Введите цвет в любом формате:
   - HEX: `#FF5733`
   - RGB: `rgb(255, 87, 51)`
   - HSL: `hsl(11, 100%, 60%)`
2. Результат автоматически показывается во всех трёх форматах.
3. Прямоугольник предпросмотра показывает реальный цвет.

**Ожидаемый результат:** Цвет конвертирован и отображён во всех форматах с визуальным превью.

---

#### 3.7.3 Конвертер временных зон

**Переход:** Вкладка **«Часовые пояса»**

**Порядок действий:**
1. В поле даты/времени введите значение в формате `ГГГГ-ММ-ДД ЧЧ:ММ`.  
   Для быстрой вставки текущего времени нажмите кнопку **«Использовать сейчас»**.
2. В первом выпадающем списке (**«Из»**) выберите исходный часовой пояс.
3. Во втором выпадающем списке (**«В»**) выберите целевой часовой пояс.
4. Нажмите кнопку **«Конвертировать»**.

**Ожидаемый результат:** В поле результата отображается дата и время в целевом часовом поясе.

---

#### 3.7.4 Конвертер JSON / XML

**Переход:** Вкладка **«JSON / XML»**

**Порядок действий:**

**Форматирование (pretty-print):**
1. Вставьте JSON или XML в поле ввода.
2. Нажмите **«Форматировать»** — текст будет выровнен с отступами.

**Конвертация форматов:**
1. Вставьте текст в поле ввода.
2. Нажмите **«JSON → XML»** или **«XML → JSON»** в зависимости от направления.

**Очистка:**
- Кнопка **«Очистить»** — удаляет введённый текст.

**Ожидаемый результат:** Отформатированный или сконвертированный текст отображается в поле результата. При ошибке парсинга показывается сообщение об ошибке.

---

#### 3.7.5 Кодировщик / Декодировщик URL

**Переход:** Вкладка **«URL»**

**Порядок действий:**

**Кодирование:**
1. Введите текст или URL в поле ввода.
2. Нажмите **«Закодировать URL»**.
3. Спецсимволы и кириллица будут преобразованы в процент-коды.

**Декодирование:**
1. Введите закодированный URL или текст.
2. Нажмите **«Раскодировать URL»** (или вставьте — декодирование происходит автоматически при обнаружении `%`-символов).

**Пример:**
- Вход: `Привет мир`
- Выход: `%D0%9F%D1%80%D0%B8%D0%B2%D0%B5%D1%82%20%D0%BC%D0%B8%D1%80`

---

#### 3.7.6 История конвертаций

В правой части экрана (или в нижней панели на мобильных устройствах) отображается **история последних 30 конвертаций** по всем инструментам.

Для каждой записи показывается:
- Тип конвертера (NUM / CLR / TZ / XML / URL)
- Фрагмент исходного и результирующего значений
- Время выполнения

**Восстановление из истории:**
- Нажмите на запись → поле ввода заполнится исходными данными, активируется соответствующий конвертер.

**Очистка истории:**
- **«Очистить сегодня»** — удаляет только записи текущего дня (с подтверждением)
- **«Очистить всё»** — удаляет всю историю конвертаций (с подтверждением)

### 3.8 Аналитика и отчётность

#### Назначение

Модуль аналитики агрегирует данные всех модулей и предоставляет статистику, графики и рекомендации по личной продуктивности. Поддерживает настраиваемые периоды и экспорт отчётов.

   - **«Неделя»** — последние 7 дней

   - **Все модули** — сводная статистика

#### 3.8.2 Метрики продуктивности

Экран отображает карточки с основными показателями и их изменением по сравнению с предыдущим аналогичным периодом:

| Метрика | Описание |
|---|---|
| Привычки выполнено | Число отмеченных привычек за период |
| Задачи закрыты | Число задач, переведённых в статус «Выполнено» |

| Помодоро-сессий | Число завершённых рабочих сессий |
| Время фокуса | Суммарное время рабочих сессий (часы и минуты) |
| Заметок создано | Число новых заметок за период |

Дельта (изменение к предыдущему периоду) отображается со знаком «+» или «–».

---

#### 3.8.3 График продуктивности

На экране аналитики отображается **линейный или столбчатый график** по дням выбранного периода:
- По оси X — дни периода
- По оси Y — число выполненных действий
- Цвета: привычки, задачи и помодоро обозначены разными цветами

---

#### 3.8.4 Инсайты и рекомендации

Приложение автоматически генерирует текстовые блоки на основе ваших данных:

**Инсайты** (наблюдения): 3–4 факта о вашей активности, например:
- «Лучший день недели — четверг: выполнено X действий»
- «Средняя длительность помодоро-сессии — Y минут»

**Рекомендации** (2–3 совета), например:
- «Попробуйте увеличить дневную цель по привычкам»
- «Большинство просроченных задач приходится на понедельник»

---

#### 3.8.5 Экспорт отчёта

**Порядок действий:**
1. Настройте нужный период и фильтр.
2. Нажмите кнопку **«Экспорт»** или **«Сгенерировать отчёт»**.
3. Выберите формат:
   - **HTML** — форматированный отчёт для печати или архива
   - **CSV** — табличные данные для обработки в Excel
4. Файл будет сгенерирован и предложен для сохранения или отправки через системный диалог «Поделиться».

**Ожидаемый результат:** Отображается статус «Отчёт готов» и открывается диалог сохранения/шеринга.

## 4. Аварийные ситуации

### 4.1 Типичные ошибки и способы устранения

| № | Ситуация / Сообщение | Возможная причина | Рекомендуемые действия |
|---|---|---|---|
| 1 | Приложение не запускается | Не установлена среда выполнения .NET 10; недостаточно памяти | Установите .NET 10 Runtime с официального сайта Microsoft; закройте другие приложения и повторите запуск |
| 2 | Приложение зависает при запуске | Повреждена база данных; конфликт версий схемы БД | Перезапустите приложение. Если не помогает — удалите файл `edudev-tracker.db3` из директории данных приложения (данные будут утеряны) |
| 3 | «Название обязательно» | Поле «Название» оставлено пустым (привычка или задача) | Введите название в соответствующее поле |
| 4 | «Слишком короткое название» | Название задачи содержит менее 3 символов | Введите название длиннее 3 символов |
| 5 | «Дата не может быть в прошлом» | Выбранный дедлайн задачи уже прошёл | Укажите дату и время в будущем |
| 6 | «Пароли не совпадают» | При регистрации значения в полях «Пароль» и «Подтверждение» различаются | Повторно введите пароль в оба поля, убедившись, что они совпадают |
| 7 | «Email уже занят» | Аккаунт с указанным email уже существует в базе | Используйте другой email или войдите в существующий аккаунт |
| 8 | «Некорректный формат email» | Введённый email не соответствует формату `name@domain.com` | Проверьте правильность ввода: должны быть символ @, точка и доменная зона |
| 9 | «Пароль слишком короткий» | Пароль при регистрации содержит менее 8 символов | Придумайте пароль длиной не менее 8 символов |
| 10 | «OAuth-вход недоступен на этой платформе» | Платформа не поддерживает OAuth (некоторые сборки для macOS/Windows) | Используйте вход по email и паролю или локальный режим |
| 11 | Уведомления не приходят | Уведомления для приложения отключены в настройках ОС | Перейдите в Настройки устройства → Приложения → EduDev Tracker → Уведомления → Включить |
| 12 | Помодоро не работает в фоне (Android) | Система Android ограничивает фоновые процессы для экономии батареи | Перейдите в Настройки → Батарея → Оптимизация → EduDev Tracker → Не оптимизировать |
| 13 | Файл вложения не открывается | На устройстве отсутствует приложение для данного типа файла | Установите приложение, поддерживающее этот тип файла (например, PDF-ридер) |
| 14 | «Выберите хотя бы один день» | При создании задачи с еженедельным повторением не выбран ни один день недели | Отметьте хотя бы один день недели для повторения |
| 15 | Экспорт отчёта не работает | Нет разрешения на запись в хранилище (Android/iOS) | Разрешите приложению доступ к хранилищу в настройках ОС |
| 16 | Данные не отображаются после входа | Профиль в базе данных не найден (БД была очищена) | Повторно зарегистрируйтесь или создайте локальный профиль |
| 17 | Поиск по заметкам не работает | FTS-индекс повреждён | Перезапустите приложение; при повторении — переустановите приложение |
| 18 | Конвертер показывает ошибку | Введённые данные не соответствуют ожидаемому формату | Проверьте формат ввода (см. подсказки в каждом конвертере) и повторите |

### 4.2 Восстановление после сбоев

#### Некорректное завершение работы (зависание / принудительное закрытие)

1. Перезапустите приложение.
2. Проверьте целостность последних данных: заметки автосохраняются, задачи и привычки сохраняются по кнопке «Сохранить».
3. Если приложение не запускается — перезагрузите устройство.

#### Повреждение базы данных

> **Внимание:** Следующее действие приведёт к безвозвратной потере всех данных.

1. Перейдите в директорию данных приложения:
   - **Windows:** `%LOCALAPPDATA%\Packages\[AppId]\LocalState\`
   - **Android:** Внутренняя память → `/data/data/[package]/files/`
   - **iOS:** Директория документов приложения в Sandbox
2. Найдите и удалите файл `edudev-tracker.db3`.
3. Запустите приложение — база данных будет создана заново.

#### Потеря сессии (выброс на экран входа)

Сессия хранится в системных Preferences устройства. Если сессия была сброшена:
1. Войдите заново с теми же учётными данными.
2. Данные в базе данных сохранены.

### 4.3 Диагностика

**Режим отладки** (только для Windows/DEBUG-сборки):
- Расширенные логи выводятся в Debug Output Visual Studio при запуске из среды разработки.
- Отдельные ошибки могут фиксироваться в консоли как `System.Diagnostics.Debug.WriteLine`.

**Проверка корректности данных:**
- Перейдите в **«Аналитика»** → выберите период **«Неделя»** — если данные отображаются, база данных работает корректно.
